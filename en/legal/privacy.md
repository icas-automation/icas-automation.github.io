# Privacy & Data Protection Policy

*Last updated: 2026*

## 1. Local Architecture (Cloud-Free)
The philosophy of **ICAS Automation** is built on complete privacy and absolute local autonomy:
* The Software (QuickApps) runs **100% locally** inside the processor of your Fibaro Home Center 3 / Yubii Home hub.
* The Software code **does not send, collect, or analyze** any telemetry data, usage statistics, or personal data on external cloud servers.

## 2. Processing of Personal Data
ICAS software extensions do not collect personal data of household members. All state databases, variables, and schedules are stored exclusively in the local memory of your Smart Home hub and are subject to the privacy policy of the hub manufacturer (FIBARO / Nice).

## 3. Contact Forms and Website (If Applicable)
When using our website (e.g., to purchase a license or request support), we process only the data necessary to fulfill the order (e.g., email address, billing information) in compliance with GDPR regulations. This data is not shared with third parties for marketing purposes.

## 4. User Rights
The User has the right to stop using the Software at any time by removing it from the hub, which physically erases all installed modules from the local device memory.
