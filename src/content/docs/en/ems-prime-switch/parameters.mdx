The module offers extensive customization capabilities to suit individual user needs, system characteristics, and expected outcomes.

After successful installation, the module adopts a default configuration that ensures basic and safe operation. However, the user can modify individual parameters at any time.

The following sections provide a detailed overview of each parameter, including basic information, its impact on system operation, and tips and recommendations.

## How to Read Parameter Descriptions

This section outlines the properties included in the initial parameter descriptions.

| Property | Description |
| :--- | :--- |
| **Parameter Type** | Specifies the parameter type:<ul><li>**Boolean**: accepts `true` or `false` values.</li><li>**String**: accepts any character sequence following the specified syntax for that parameter.</li><li>**Integer**: accepts a numerical value.</li></ul> |
| **Default Value** | Specifies the value adopted by the parameter if no value is explicitly provided. |
| **Editable** | Specifies whether the parameter can be edited: `true` indicates that the parameter can be modified by the user, while `false` indicates that the value is managed exclusively by the system. |
| **Value Range** | Specifies the range of allowed values for the parameter, presented as a minimum and maximum value or a list of values. This property does not apply to all parameters. |

## How to Change Parameter Values in the Fibaro Interface?

Parameters are modified through the standard user interface of the Fibaro gateway (Home Center 3 / Yubii Home) in the section dedicated to device variables. To make changes, follow these steps:

<Steps>
  1. Log in to the **Fibaro** admin panel.
  2. Go to the *Devices* tab in the side menu.
  3. Find and open the device from the list.
  4. Go to the **Variables** tab at the top of the device view.
  5. Find the variable corresponding to the parameter you wish to change.
  6. Enter the new value in the text field next to the variable.
  7. Save your changes by clicking the **Save** button.
</Steps>

<Aside type="caution" title="TIP">
  Before applying changes, ensure that the entered values comply with the allowable range for the given parameter. Incorrect values may affect the proper operation of the module.
</Aside>

| Property | Description |

### SWITCH_PWR_THLD

The `SWITCH_PWR_THLD` parameter specifies the device's power threshold percentage that must be covered by solar surplus power for the device to turn on. The default value of 100% means the device will only start when surplus energy fully covers the power defined in the `SWITCH_PWR` parameter.

| Property | Description |
| :--- | :--- |
| **Parameter Type** | Integer |
| **Default Value** | `100` |
| **Editable** | `true` |
| **Value Range** | Greater than 0 |

<Aside type="caution" title="TIP">
  For smaller installations with low surplus power, it is worth lowering this parameter to e.g. 50%. The device will then switch on when PV covers at least half of the required power—the rest will be drawn from the grid, allowing you to maximize available solar energy.

  If you have a large system and multiple devices competing for power, it is better to leave the value at 100% or higher.
</Aside>

| **Parameter Type** | Integer |

| **Editable** | `true` |
| **Value Range** | Greater than 30 |

### MIN_RUN_TIME

The `MIN_RUN_TIME` parameter specifies the minimum operating time (in seconds) of the device once turned on, regardless of surplus availability. This prevents excessive device cycling, protecting its components from wear and failure.

| Property | Description |
| :--- | :--- |
| **Parameter Type** | Integer |
| **Default Value** | `1200` |
| **Editable** | `true` |
| **Value Range** | Greater than 30 |

<Aside type="danger" title="IMPORTANT">
  Adjust this parameter value with great care to avoid damaging equipment components. Below is a list of common appliances alongside suggested minimum runtimes:
   - **Boiler / Electric Water Heater**: 30–60 minutes (1800–3600 s). Water needs time to noticeably increase in temperature. Short cycles of 2–3 minutes only wear down relay contacts without producing real heating effects.
   - **Heat Pump (DHW / Space Heating)**: 30–45 minutes (1800–2700 s). Highly critical! Compressors in heat pumps and air conditioners tolerate short cycling very poorly. Frequent restarts drastically shorten device lifespan.
   - **Air Conditioning (Cooling/Heating)**: 20–30 minutes (1200–1800 s). Similar to heat pumps—refrigerant pressure and flow need several minutes to stabilize after compressor activation.
   - **Pool Pump / Filtration**: 30–60 minutes (1800–3600 s). Pool water circulation is effective only over longer operational spans. Additionally, induction pump motors consume the most current during startup.
   - **EV Charger (Electric Vehicle)**: 15–30 minutes (900–1800 s). EV battery packs and internal charge controllers (BMS) require up to several seconds to negotiate charging current. Constant interruption and resumption can cause vehicle computer errors.
   - **Dishwasher / Washing Machine / Dryer**: Full cycle duration (e.g., 60–120 min). Unless the appliance features a pause state, cutting power mid-program will trigger errors or reset the cycle entirely.
   - **Electric Heater / Space Heater**: 10–15 minutes (600–900 s). Heaters (especially oil-filled radiators) have high thermal inertia. Short cycles will not heat spaces effectively.
   - **Dehumidifier / Humidifier**: 15–20 minutes (900–1200 s). Allows ambient humidity levels to balance out and avoids rapid cycling of the dehumidifier compressor.
   - **Garden / Decorative Lighting**: 5–10 minutes (300–600 s). Ensures visual consistency (prevents flickering across the garden when clouds temporarily cover the sun).
</Aside>

### POWER_ON_RULE

The `POWER_ON_RULE` parameter defines the custom logic condition that must be met for the device to launch (e.g., temperature below 55°C). The parameter value is a boolean expression following the `[ID:property]` syntax, evaluated by the system in real time.

Example:
`[123:value] > 55 and [234:value] < 0`

| Property | Description |
| :--- | :--- |
| **Parameter Type** | String |
| **Default Value** | `TRUE` |
| **Editable** | `true` |
