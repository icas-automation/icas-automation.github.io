##### 1. Local-First Architecture & License Verification
The philosophy of **ICAS Automation** is built on complete privacy protection and total local control autonomy:
* Local Decision Logic: The software (QuickApp) runs **100% locally** on your Fibaro Home Center 3 / Yubii Home processor. All calculations, state machines, and decision algorithms execute without cloud involvement.
* Network Connectivity: Network communication is used strictly for periodic, **secure software license verification**.
* Technical Data Scope: During license verification, only minimal technical identifiers are transmitted and stored on the server:
    * Hub Serial Number: Used solely to identify the device and match its license state.
    * App Class: Identifier for the specific software variant.
    * UI Language: Used for basic analytics to prioritize language support.
* No Telemetry: The software does not collect, transmit, or analyze any personal data, user habits, sensor states, network topology, or telemetry data.

##### 2. Processing of Personal Data
ICAS software extensions do not collect personal data of household members. All state databases, variables, and schedules are stored exclusively in the local memory of your Smart Home hub and are subject to the privacy policy of the hub manufacturer (FIBARO / Nice).

##### 3. Contact Forms and Website (If Applicable)
When using our website (e.g., to purchase a license or request support), we process only the data necessary to fulfill the order (e.g., email address) in compliance with GDPR regulations. This data is not shared with third parties for marketing purposes.

##### 4. User Rights
The User has the right to stop using the Software at any time by removing it from the hub, which physically erases all installed modules from the local device memory.
